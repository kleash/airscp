# Files

The **Files** tab has two panes. The left pane shows this Mac (or another connected server). The right pane shows the
selected server. Drag between them to copy.

{% include shot.html name="files" alt="The Files tab: this Mac on the left, the server on the right" %}

## Tips

- Right-click a file for everything you can do with it.
- A command that a server can't run is greyed out, and its tooltip says why (for example an account that allows file
  transfers only).
